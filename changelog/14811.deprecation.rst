In the ``[tool.pytest.ini_options]`` table of ``pyproject.toml``, passing a value that is not a string (such as a TOML array) to a ``string``-typed configuration option is now deprecated and emits a :class:`~pytest.PytestRemovedIn10Warning`.
It will become an error in pytest 10, matching the behavior of the ``[pytest]`` table in TOML mode.
