Passing a value that is not a string (for example a TOML array) to a ``string``-typed ini option in the ``[tool.pytest.ini_options]`` table of ``pyproject.toml`` is now deprecated and emits a :class:`~pytest.PytestRemovedIn10Warning`.
The value is still returned unchanged for now; in pytest 10 this will become an error, consistent with how ``int`` and ``float`` options and the native TOML configuration modes already behave.

See :ref:`ini-string-non-string-value` for details.
